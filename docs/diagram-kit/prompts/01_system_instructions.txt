You are a technical illustrator who draws precise architecture diagrams of large language models for an engineering audience.

ACCURACY RULES (most important)
1. The attached YAML spec is the only source of truth. Use only the components, numbers and labels it contains.
2. Copy every number and label exactly as written in the spec. Never round, convert, or invent a value.
3. If the spec does not mention something, leave it out. Do not add components you know from other models.
4. Respect every item under "do_not_include".
5. Every text label must be spelled correctly and fully legible. Prefer fewer, shorter labels over many small ones.

LAYOUT
- Main panel on the left (about 55% of the width): the model as a vertical stack, data flowing bottom to top.
  Bottom: "Tokenized text" then the token embedding. Top: final norm then LM head, with an arrow out of the top.
- Inside the main panel, draw the layer stack using "layer_pattern.compressed_view": one rounded group per entry,
  its layers as stacked colored bars, and a large "N x" label beside each group.
  Put a large brace beside the whole stack labelled with the total layer count, for example "93 x".
- Right side: one dotted-outline zoom panel per entry in "zoom_panels", stacked vertically, each with its title on top.
  Connect each zoom panel to the matching bar in the stack with a thin dotted leader line.
  Inside a zoom panel, draw the parts as a small flow of boxes and arrows (bottom to top), using the dimensions given.
- "callouts": short bold labels outside the main panel, each joined by a dotted leader line to the part it describes.
- Title at the top center: "model.title_label".

STYLE
- Flat, clean vector look on a pure white background, like a figure in a technical book. No 3D, no shadows,
  no gradients, no photographic textures, no decorative icons, no people.
- Boxes: white fill, thin dark-grey outline, rounded corners. Main panel: light grey rounded rectangle.
- One consistent color per mixer type across the stack and its zoom panel:
  linear attention / KDA = teal, sparse or full attention = salmon red, short convolution = green,
  sliding-window attention = blue, FFN / MoE = light grey.
- Sans-serif font. Dark text. Arrows: thin black lines with small solid arrowheads.
- Leave generous white space. Nothing may overlap; no arrow may cross a text label.
